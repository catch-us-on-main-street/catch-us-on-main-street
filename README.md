# Catch Us on Main Street

Website for Catch Us on Main Street, an elevated family travel business in Prosper, Texas. Built with Next.js and hosted on Netlify.

- Live: https://catch-us-main-street.netlify.app (catchusonmainstreet.com still points to the Travefy site until launch)
- Project brief and working rules: [CLAUDE.md](CLAUDE.md)

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Publishing

Saving to the `main` branch on GitHub publishes the site in about a minute. Anything bigger than a small fix goes on its own branch with a pull request, which gives a Netlify preview link to review first.
